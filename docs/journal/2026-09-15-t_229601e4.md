# Decision: `claim.schema.json` describes the L1 record — the extraction materialization block is enumerated (ADR-0011)

## Intent

Decide whether `schemas/v0.5.0/claim.schema.json` describes the **L1 claim version record** (the line
the reference implementation appends) or the **spec §6 claim version** (with the L1 line a documented
superset) — and make the repo state the chosen truth, because an active record the library writes
carried a `semantic` block the published schema rejected (`additionalProperties`).

**Out of scope:** the `operation_id` half of the same measurement (done in `t_85817375`), the writer
(`src/`), and any schema other than `claim.schema.json`. A writer change was only on the table if the
decision were "stop emitting the block" (card option 3), which was rejected.

## What was done

- **Decision (ADR-0011, Status: Proposed — owner approval gates merge):** the schema describes the L1
  record, so its envelope is enumerated in it, including an **optional, closed** `semantic` block
  (`schemas/v0.5.0/claim.schema.json`, `SHA256SUMS` regenerated, `schemas/v0.5.0/README.md` gains
  *What `claim.schema.json` describes*). Required set, every existing property, and every other schema
  are untouched; the block is not a wire field and no conformance claim depends on it.
- **Bounds are the writers' declared types, not policy.** `extracted_confidence` carries no
  `minimum`/`maximum` (measured: `insertClaim` copies a caller's `1.5` verbatim, so a 0..1 bound would
  have re-created the very defect this closes) and valid-time values accept a pass-through string (the
  LLM path copies the model's `validity.from`). Both decided from measurement/code, not preference.
- **Tests.** `test/schemas-v0.5.0.test.ts` gains the block's fixture group; the pinned
  `test/layer1/legacy-operation-id.test.ts` now asserts the record's **whole** Ajv error list is empty
  (it previously pinned the divergence by name); `test/semantic-materialization.test.ts` validates the
  records `reflect.auto` appends, read as raw JSONL bytes.
- **Two same-class divergences measured and carded, not absorbed:** `t_3ba3ee39` (`insertClaim`'s
  forgotten path omits `supersedes`) and `t_9a700aed` (pod-profile `pod/<pod>/<lane>` scopes and
  `substrate:<ULID>` actor ids vs the v0.5.0 patterns). Both recorded in ADR-0011 → *Known
  divergences* with their raw probe output.
