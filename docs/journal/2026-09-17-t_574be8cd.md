# The remaining `personal` literals: measured, decided, fixed on one lane — the confidence half-life table, the session summariser default, the OBSERVE example, the vestigial wiki directories

## Intent

`t_e6fce49a` fixed the four writer sites (GRANT, REVOKE, and the two `?? 'personal'` fallbacks) and
measured, carded and deliberately left every *other* `personal` literal in `src/`. This card decides
each of the four: **defect → fix + pin + A/B pair**, or **deliberate → say so where integrators read
it** (`schemas/*/README.md`, `docs/conformance-status.md`). It also had to state which item is the
**owner-gated class** before anything merges.

Sites, as the card states them: (1) `src/layer1/confidence.ts`'s 365-day half-life keyed on the legacy
lane; (2) `src/protocol/session.ts`'s summariser default; (3) `src/index.ts`'s OBSERVE tool-description
example; (4) `wiki/personal`, `wiki/workspace`, `wiki/project`, created by init and read by nothing.

**Out of scope, as the card directs:** the four writer sites (fixed in `t_e6fce49a`), the `reflect()`
no-scope sentinel (`t_27c73d58`, PR #27), and `src/protocol/forget_scope.ts`'s
`if (ids.includes('personal')) return 'personal'` — left exactly as written, because it is a
legacy-*registry* fallback (pod-scope resolution, not a hard-coded lane) and it resolves to `self` in
every registered brain.

## What was done

Branch `wip/tech-head/remaining-personal-literals`, stacked on `wip/neo/consent-change-scope` @ `658c3cb`
(PR #24, unmerged). One commit per item, so the owner-gated one can be dropped on its own.

### 1. `src/layer1/confidence.ts` — **defect**, and the **owner-gated class** (`e6e139e`)

The half-life table was keyed on the *pre-rename spellings* — a `personal` key (365 days) and a
`project/` prefix (30 days) — so neither override this implementation **declares**
(`staleness.scope_overrides: { self: 365, 'project:*': 30 }` over `default_half_life_days: 90`)
reached the lane the published `$defs/Scope` vocabulary names. The table is now keyed on the
vocabulary (`self`, `project:<id>`).

Measured by reading the *applied* half-life back out of the shipped `computeConfidence` (probe:
`solve` from three ages of the same claim, so the numbers are the function's, not a restatement of
the table — `probe/half-life-per-scope.mjs`):

```
spelling            vocabulary    pre-fix (658c3cb)   post-fix
self                yes                  90 d            365 d   <- the declared pod override
personal            no                  365 d             90 d
workspace           yes                  90 d             90 d
project:default     yes                  90 d             30 d   <- the declared project override
project:foo         yes                  90 d             30 d
project/foo         no                   30 d             90 d
pod/p1/personal     host lane            90 d             90 d
pod/p1/workspace    host lane            90 d             90 d
client:acme#1       yes                  90 d             90 d
agent:neo           yes                  90 d             90 d
```

Effect on the public surface (on a 180-day-old claim, identical in every other respect):
`self` 0.3475 → **0.41657**, `project:<id>` 0.3475 → **0.31234**, `personal` 0.41657 → 0.3475,
`workspace` unchanged at 0.3475.

Owner gate, stated plainly: `computeConfidence` runs on the §1e fact-resolution write path
(`resolveFactMatches`), in `replay` and in `conflicts`, so **every `self`- and `project:<id>`-scope claim
written from here carries a different number than before**, and `./layer1/confidence` is a published
package subpath (`package.json` `exports`). No published schema byte moves and no artifact shape
changes (values only). **Not to be merged without the owner's call.**

### 2. `src/protocol/session.ts:205` — **defect** (`230c8cc`)

`session.requested_scopes[0] ?? 'personal'` → `?? POD_SELF_SCOPE`. Driven end to end (the fix is the
same one spelling the writers already use): a session started with `requested_scopes: []` and ended
with an `onSummarize` callback was handed `personal` pre-fix and is handed `self` now, and the lane it
is handed is one the brain registers. Host-visible, disclosed: the *argument* a host callback receives
moves lane. Nothing in the library persists on this path (the callback is the host's), so no canonical
record changes; the primary path is untouched (a session that declared a scope still hands its own
lane — pinned as the A/B control).

### 3. `src/index.ts:251` — **defect** (`25444a7`)

The OBSERVE scope description read `Scope identifier (e.g. personal, project/foo)` — both examples
off-vocabulary (`personal` is not a scope at all; the spec form is `project:<id>`). Now
`e.g. self, project:foo, client:acme#1`. `src/mcp.ts` carries no such string (checked: its scope
parameters only show `client:acme#1`), so this was the only site.

### 4. `wiki/personal` / `wiki/workspace` / `wiki/project` — **defect** (`3a7ab0a`)

Init (`initialiseDataDir` in `src/core.ts`, `initialize` in `src/index.ts`) created three directories
that appear in no normative layout and that nothing in `src/` reads or writes (grep-verified): spec
§9's L2 conventions enumerate `concepts`, `entities`, `decisions`, `synthesis`, `tombstones`,
`profiles` (plus `_index.md`), the compiler creates the category directory it writes into
(`layer2/compiler.ts:406`), and the manifest creates the root (`writePrivateFile` makes the parent).
They were the last trace of the pre-rename lane spelling in an on-disk layout, and a host reading a
data dir could reasonably take them for a convention. Init now creates the wiki root explicitly and
nothing else.

## Unresolved

- **Owner gate (item 1):** the confidence values move for `self`- and `project:<id>`-scope claims. The
  direction is the one the config declares, but it is a value change on a published subpath, so it is the
  owner's call. Commit `e6e139e` is isolated for exactly that reason.
- **No ADR was minted for the value change**, deliberately: no artifact shape, no schema byte, no verb —
  only the number the formula yields. A reviewer may disagree; if so, the place for it is an ADR-0015
  delta (the lane-identity boundary the table was mis-keyed on), not a new number.
- **Legacy values move on their next touch, not retroactively.** Pre-fix records keep the spelling they
  were written with (ADR-0015; L0 is append-only), and a legacy `personal`-scope *claim* recomputed today
  now decays at the default 90 days — measured, and the pin asserts it, so it cannot drift silently.
- **`npm run status:check`** is measured, not chased (the residual convention on this lane): board-event
  counters move with every card action, and the projection is regenerated post-close.
- **Not re-measured here (out of scope, carded elsewhere):** `reflect.ts`'s no-scope sentinel
  (`t_27c73d58`) and `forget_scope.ts`'s legacy-registry fallback (deliberately untouched, card instruction).
