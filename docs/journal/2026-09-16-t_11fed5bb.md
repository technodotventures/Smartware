# L1 claim record — which schema covers it (ADR-0013 → Delta), and a test that fails when the boundary moves

## Intent

The independent Coffee gate (`t_66f1dd7d` §3 B2) measured, on the packaged build, that the ordinary
write path emits canonical claim records which fail the published `claim.schema.json`: an undeclared
`semantic` block (123/143 records) and `operation_id: "op_LEGACY00000000000000000000"` (125/143). It
recorded the `semantic` half as the third instance of the question ADR-0013 answered for the L0
record and the L2 page frontmatter, and asked for a decision plus a boundary pin.

Bounded objective: decide **which schema covers `<dataDir>/claims/<yyyy-mm>.jsonl`** — the artifact
`EXPORT.SCOPE` ships as `claims.jsonl` — say for each divergence **which side is wrong**, record it as
an ADR-0013 amendment, and pin the answer with a test that fails when the boundary moves.

**Explicitly out of scope:** fixing either divergence (the fix lanes already existed and were reviewed:
ADR-0011 → `981e5a7`; `t_85817375` → `0a68482`), composing them onto this lane, the `supersedes`
writer/schema divergence (`t_3ba3ee39`, another lane), host-registered lanes (ADR-0015 boundary), the
replay-minted ids (`t_0b079fbf`) and the retention fallback id (`t_0177d9c3`), and moving any
published schema byte.
